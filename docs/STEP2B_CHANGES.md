# STEP 2B 변경 내역 (근거·문구 수정)

범위: **문구와 근거 표기만** 바꿨다. 색, 레이아웃, 컴포넌트 구조, 인터랙션은 바꾸지 않았다.
(예외: 아래 "시각 요소가 바뀐 곳" 참고. 모두 기존 디자인 토큰 안의 값이다.)
변경은 `src/` 에서 했고 `python3 tools/build.py` 로 다시 번들했다.

공식 문서로 확인된 정책은 **0건**으로 표기했다 (P05 우측 배지: "공식 확인 0건 · 원문 확인 전").
국내 예매처 전반에 대한 일반화(예: "예매 후 좌석을 직접 바꿀 수 없다")는 모두 제거했다.

## 사용한 리서치 수치 (보고서 기준, 변경 없음)

X 공개 교환글 21건 (2026-11-18): 유형 좌석 9 / 회차 7 / 좌석+회차 5, 회차 조건 19, 구역 18, 열 10,
캐스팅 7, 평균 조건 3.86개, 명시적 연석 요청 0건, 실제 교환 결과 확인 0건.
집계 기준: 희망·허용 교환 조건에 명시된 경우만 센다. 보유석에만 적힌 날짜·회차는 제외하고, 같은 차원의 복수 대안은 1개로 센다.
평균 3.86개는 회차·구역·열·캐스팅만이 아니라 정산·권종·등급 등 다른 조건을 포함한 값이다.
조건별 언급 건수는 게시글 수이므로 합산해 총 조건 수로 해석하지 않는다.
**원본 분류 엑셀로 검증하기 전이므로 수치는 바꾸지 않았다.**

## 시각 요소가 바뀐 곳 (모두 기존 토큰 안의 값)

- 상태 태그(`완료`, `미실시`, `확인 필요`, `가상 규칙`, `시스템 기능`)를 P04·P05 제목 옆에 추가. 12px 배지 스타일은 P07/P09의 기존 배지와 같고 색은 기존 팔레트(`#A3440B`/`#FFF1E6`, `#4A4F5C`/`#F0F1F4`, `#3A26C4`/`#E9E5FF`, `#1F7A4D`/`#E6F6EE`)를 쓴다. 색만이 아니라 텍스트를 함께 표시한다.
- P04: 집계 기준 각주 1줄 추가 (14px, 기존 보조 텍스트 색).
- P08 PairSeat·P09: "상대에게 유리" 배지의 색을 초록(긍정)에서 회색으로 바꾸고 문구를 "상대 좌석 변경"으로 바꿨다. 초록은 "이득"을 암시하기 때문이다.
- P08 KEY DECISION: 7열/11열 설명의 빨강·초록 강조색을 제거했고 "추천" 배지를 삭제했다 (앞열이 더 좋은 자리라는 단정 제거).
- 레이아웃: 길어진 문구로 줄 수가 늘어난 곳은 있으나 컨테이너 밖으로 넘치거나 잘린 곳은 없음을 스크린샷으로 확인했다 (`verify/results-2b/desktop/`).

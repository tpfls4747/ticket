수락과 완료는 다른 상태예요

A좌석·회차 교환 (핵심 기능)양쪽이 명시적으로 수락하고 최종 확인을 통과해야 '교환 완료'를 표시해요
교환 신청조건을 등록하고 후보를 찾아요내 티켓: 유효
후보 발견양방향 조건 확인을 통과해요. 매칭 완료가 아니에요내 티켓: 유효
제안 전송내가 동의(수락)하고 제안을 보내요내 티켓: 유효
상대방 검토상대방이 제안을 확인해요내 티켓: 유효
제안 수락상대방도 동의했어요. 아직 완료가 아니에요내 티켓: 유효
최종 확인 중티켓·조건·정책 상태를 마지막으로 확인해요내 티켓: 유효
교환 완료확인을 통과한 뒤에만 표시해요 (시연용 모의)새 티켓 (모의)
거절상대방 검토 중 거절 → 내 티켓 그대로
취소신청자가 최종 확인 전에 취소 → 내 티켓 그대로
실패최종 확인 실패 → 원 티켓 유지가 목표 (목표 UX·시스템 요구사항)
B연석 만들기 (실험 기능 · 수요 미검증)일반 교환의 앞에 의향·인접·동행석 확인 단계가 붙어요
교환 제안 받기 (사전 의향)'교환 제안 받기'를 켠 관객만 후보가 돼요켜지 않으면 제안을 보내지 않아요
인접·자격 확인배치도로 인접 여부와 교환 자격을 따로 확인해요확인 못하면 제안 보류
동행석 분리 안내거절·실패하면 떨어진 좌석이 유지될 수 있어요전후 좌석 비교 + 내 동의
제안 전송상대방 검토제안 수락최종 확인 중이후는 일반 교환과 같은 상태로 진행해요. 수신자는 언제든 거절할 수 있고, 수락은 완료가 아니에요
예외 상황 → 상태모든 상태와 데이터는 시연용 모의예요. 실제 매칭·처리 기능은 없어요
후보 제외필수 조건 불일치후보 목록에 올리지 않고 이유를 보여줘요
후보 없음교환 가능한 후보 없음신청은 유지하고 조건을 넓히도록 안내해요
